# `tools/` — delegate instruments, indexed

**What this directory is.** Read-only instruments the **delegate** runs to establish rig state, price an
operating decision, or audit a competitor. They are **not `check` rules and not seat-facing**: a delegate runs
them, a seat does not, and none of them writes to the store, the rig, or the tree unless the verb is named
(`--write`, `--start`). Every instrument prints the **patterns and thresholds it counted**, because a count with
no pattern is not evidence (D142). The product-side halves of these ideas are registered as ROADMAP items
(`check` rules are the team's work, not the delegate's). **Every timing below is `real` from this box** — Linux
(`label-withheld-per-D205`, Fedora `7.2.11-200.fc44.x86_64`), `node v24.22.1`, store `./selfdev.sqlite` (273,995 entries),
2026-10-28T16:4xZ — and every **exit code was re-measured rather than copied from a draft**: that habit caught two stale
rows in the same hour it wrote this table (`competitor-brief --check` is **0.03 s · exit 2**, not "0.11 s · exit 1").
Re-measure a row when you touch its tool; a cost table that drifts is worse than no table.

**Read this before writing a probe.** The last sessions each spent part of an hour re-deriving a read that already
shipped (`scripts/read-constitution.mjs`; store queries that `tools/edit-failure-rate.mjs` now prints in ~2.6 s). It
happened **twice in one session even after the lesson was written into a pitfall list** — which is why the fix is this
index rather than more prose (D150 §2). Discovery by `ls` + guessing is the slow path; this index is the short one. Also check `scripts/` — the
product ships helpers (`scripts/read-constitution.mjs`, `scripts/clockin.mjs`, `scripts/sync-pi.mjs`,
`scripts/test.mjs`).

## Rules these instruments follow (and one they deliberately do not)

- **Read-only unless the verb says otherwise.** `--status`, `--check`, `--dry-run`, `--kinds`, `--json` write
  nothing; `--write` (pins) and `--start`/`--stop` (broker) are the only writing verbs, and `--start` refuses
  without preflight acks (`--allow-dirty`, `--yes-pm-wakes`) that belong to the operator.
- **Print the pattern, print the zeros.** A zero you cannot interpret is a finding: the Linux no-seat-shell
  discovery (D149 §4, ROADMAP 217) came from printing **every** tool name's count, not just `edit`'s —
  `"toolName":"bash"` was 0 of 137,368 entries.
- **They are not `check` rules.** Enforcement belongs in `cli.mjs check` and that is seat/devtools work: the
  registered halves are ROADMAP 202 (review audit), 208 (context fraction), 210 (seat cwd resolves on this
  host), 211 (latent byte faults), 213 (clock-in `PROOF COMMANDS` — the block that should print the commands in
  this table at clock-in), 215/216/217/218 (edit-side).
- **Query the store from a file, not from `node -e`.** SQLite wants `'table'` in single quotes (double quotes are
  identifiers) and a single-quoted shell string cannot contain single-quoted SQL; `LIKE` is ASCII-case-insensitive.
  Scratch probes go in **`.spike/`** (gitignored) — `.scratch/` is **not** gitignored, so probes there sit one
  `git add -A` away from history.
- **`node --check tools/<file>.mjs` before you run a tool you just wrote** (0.02 s). A `tools/` instrument written this
  session died on `SyntaxError: Missing } in template expression`, and the offending template line parsed **fine in a
  standalone file** — the fault was in the surrounding context, so reading the line back at it was the slow path (6 min
  of wall-clock). `--check` finds it in hundredths of a second and names the line. Cheap guard, real saving.
- **Project the big reads; do not dump them.** `cli.mjs status` is **22.7 MB** and `cli.mjs queue --json` is **21.2 MB**
  on this store, and **`queue` has no filters** (`cmdQueue`, `cli.mjs:1018`, ignores every argument — `--status held`,
  `--to pm` return all 4,821 rows, so an unrecognized flag **fails open**). Piping either into a session's context costs
  21 MB of tokens for the 296 rows that matter. Use `jq` (`/usr/bin/jq`) or a tool:
  `node cli.mjs queue --json | jq -r '.items[] | select(.status=="held" or .status=="deferred") | [.id,.status,(.to//"-"),(.subject//""|.[0:60])] | @tsv'`
  → 296 rows in **75 KB**. Same reflex for `rig.selfdev.json` (seat `instructions` blocks are multi-KB each): select the
  keys you need, never print the file. Registered as ROADMAP **228**.
- **`tools/` is not prettier-formatted** (`cli.mjs format --check` reports every file here unformatted), so
  reformatting one instrument in a functional change is churn, not hygiene.
