# model-probes — read-only probes that produced the numbers in `docs/reviews/verifier-model-survey-2026-10-27.md`

They live here rather than in `.scratch/` because that survey cites them, and an untracked script behind a
durable citation is the same failure ROADMAP 190 exists to catch: a pointer that resolves nowhere.

Nothing here mutates the rig. They read GGUF headers, query HuggingFace, and call a running OpenAI-compatible
endpoint. They do **not** start, stop, or reconfigure a server. `gate.mjs`/`corpus.mjs` write only under
`.spike/gate/` — mutant module copies, extracted review regions, and run transcripts. Source files are never
touched: a mutant is a *copy* of a module with one substitution, imported only to be diffed against the original.

| Script | What it establishes |
| --- | --- |
| `gguf-census.mjs` | Per-class byte attribution of a GGUF (routed experts vs everything else) — the arithmetic that decided which Flint quants can exist on this box. `node gguf-census.mjs <file.gguf>` |
| `gguf-tok.mjs` | Whether a GGUF ships a chat template and whether that template handles tools. `node gguf-tok.mjs <file.gguf>` |
| `gguf-dump.mjs`, `gguf-step.mjs` | The parser-debug steps that found the GGUF KV value type is a `u32`, not a `u8` |
| `verifier-survey{,2,3,4,5}.mjs`, `devstral-nums.mjs` | HF tree sizes, `config.json` architecture/KV math, and vendor benchmark rows quoted in the survey |
| `throughput.mjs` | prefill (`max_tokens: 1`, unique text) and decode (streamed chunks) — the corrected method from **D136**. `node throughput.mjs` |
| `stream-probe.mjs` | The first streaming attempt; kept because it is where the usage-less-stream and prefix-cache artifacts showed up |
| `gate.mjs` | Runs the corpus against one endpoint in **three conditions per item** — `defect`, a matched `clean` control, and `clean-neutral` (a prompt that does not presuppose a defect) — counterbalanced per item AND rotated across replicates. Scores rubric mechanism-groups, pre-registered phantom patterns and **false alarms on controls**; reports McNemar exact p on the paired items; drops corpus artifacts from the ranking. Flags: `--compare <run.json>` (paired side-by-side, intersected on shared items), `--rescore <run.json>` (re-score a saved transcript, no prompts), `--whole-module` (feed the ENTIRE file; see **195** below), `--budget <estTokens>`, `--probe` (accept the whole module only if the endpoint answers 200 for it), `--material answer\|answer+reasoning` (**197**: what a turn is scored on, declared and printed), `--pair-comments strip-both\|keep-both\|strip-clean-only` (**199**, see below), `--replicate k` (**198**, see below), `--plan` (print the fit and pair tables, spend nothing). `node gate.mjs <baseUrl> <model-id> [label] [flags]`; transcripts land in `.spike/gate/run-*.json` so the scorer is auditable, and are rewritten **after every item** so a k-replicate arm interrupted mid-run keeps what it paid for. |
| `gate.mjs --replicate k` | **ROADMAP 198.** Runs the whole matrix k times, then scores the **majority-of-k cell**: a cell is scored only if a strict majority of the passes agree, otherwise it is `UNSTABLE` and named. Prints per-cell verdicts, the **unanimous-cell rate per axis**, the spread across replicates, and the **G2 calibration floor under both the majority run and the worst replicate** (a floor met in one draw is not a floor). The default `k = 1` still runs, but the run prints `NOTE 198: k = 1 — every verdict below is a SAMPLE`, because the missing label is what let a 4/8-vs-3/8 gap reach a routing decision (D137). |
| `gate.mjs --pair-comments` | **ROADMAP 199.** How COMMENTS are treated in a matched pair, which used to be asymmetric: the clean side was stripped, the defect side authentic — measured at **−17.7% to −68.8% of the clean side's bytes** (`src/driver.mjs` 14,023 → 4,561), so a "matched" whole-module pair was a 14 KB file against a 4.4 KB file. `strip-both` (now the default) takes comments from both sides so the pair differs by the defect and nothing else; `keep-both` leaves both authentic; `strip-clean-only` reproduces the 2026-10-28 tables. `--plan` prints the **matched-pair accounting** per item and view: raw bytes, byte delta and delta %, the bytes actually shown, the comment share of each side, and the number of comment lines on the CLEAN side carrying that item's own rubric vocabulary — the leak `keep-both` would put into a control (measured: 41 lines at H1, 51 at M2, 38 at M3, 35 at M1; 0 at H5). If stripping makes a text stop parsing, the item DOWNGRADES to `keep-both` with a loud NOTE — symmetry outranks the policy. |
| `gate-side-by-side.mjs` | Compares saved transcripts cell-by-cell (per item × condition) and runs paired exact McNemar **on the items both runs actually showed**, so a whole-module arm and a fragment arm can be compared without comparing different denominators. From a `--replicate` transcript it takes the **majority cell**, not the last row, and prints each side's unanimous-cell rate and pair policy. `PAIRS='[["name",0,1]]' node gate-side-by-side.mjs --pairs <run.json> …` |
| `corpus.mjs` | The corpus, built at run time and never retyped: historical defects from `git show <fix>^:<file>` (hunk-anchored) plus **mutants injected into current `main`, whose non-equivalence is proved by executing the clean and mutated modules against each other** — an equivalent mutant is dropped with a loud NOTE. Every window is repaired to a statement boundary and verified with `node --check`, so a region that cannot parse excludes its item instead of handing the model a `SyntaxError` to "find". Also exports `estimateTokens()` — **calibrated, not assumed**: 2.7 chars/token, above the worst measured 0.2588–0.3609 tok/char read out of recorded `usage.prompt_tokens` — and `commentLedMask()`, a small state machine (block comments, multi-line templates, `${}`) that decides which lines are comment-only. The state machine is not decoration: a line regex also matches lines *inside* template literals, and in `src/worktree.mjs`/`src/rig.mjs` those lines carry the backtick that **closes** the template, so a regex stripper unbalances the module and drops the item. |

**Two standing weaknesses of the gate, both measured.** A single run does not replicate: the same model, corpus and
scorer flipped **4 of 8** defect cells between runs while reproducing the aggregate exactly (**ROADMAP 198** — the
instrument now runs k ≥ 3 and scores majority cells, so the question is answerable rather than assumed).
And a whole-module "matched pair" was not byte-matched, because the clean side was comment-stripped and the defect
side was not — −17.7% to −68.8% of the bytes (**ROADMAP 199** — fixed in the instrument as `strip-both`, with the
leak that `keep-both` would cause measured per item). Both are re-measured in
`docs/reviews/verifier-gate-hardening-2026-10-28.md` **§11**; quote §10 with those caveats, since every number
there was produced on an asymmetric pair at k = 1.
