+# Failure ledger (`docs/FAILURE-LEDGER.md`)
+
+**One classified set of the suite's KNOWN REDS, with an owner and a clearing condition.** Landing entries and
+verify reports **cite this file** instead of restating a list. A copy goes stale the moment it is written; a
+citation points at a dated source that says when it was last true.
+
+`node scripts/failure-ledger.mjs --capture suite.err` (or `--run --jobs 6`) prints the ledger and the citation
+line, and exits 1 when the ledger no longer matches the suite: a red with **no row**, a row naming a demo that
+now **passes**, or a row whose recorded cause no longer matches what is failing.
+
+## Why this exists (#3795)
+
+The auditor's re-verify showed the same claim written into fifteen landing entries in one day:
+"KNOWN RED, do not misattribute: broker-one-connection, seat-instruction-encoding, 5 tui-durable-*". Two
+failures follow from writing a list instead of a pointer:
+
+- **The set moves and the copy does not.** impl caught pm's "seven red at 557ceb3" list (#3692) naming four
+  demos that were already green when the entry landed.
+- **The label is uniform when the causes are not.** "5 tui-durable-* are pre-existing" flattened three owners:
+  two content clobbers, two dependency-state artifacts (`ERR_PACKAGE_PATH_NOT_EXPORTED './codemode'`) and one
+  Windows `EPERM` temp-dir artifact. A verifier that cannot tell a clobber from an environment artifact
+  defaults to "ignore all red" — which is how #2279's blanket "37 pre-existing failures not introduced by this
+  change" became false in two directions at once (the set had shrunk, and the survivors were not uniformly
+  environmental).
+
+The ledger is the only artifact that makes "do not misattribute" checkable: each row names the demo, the
+class, the owner, the condition that clears it, and the date it was last measured.
+
+## The classes

+//
+// WHY THIS EXISTS. Landing entries and verify reports have spent a whole session restating lists of known
+// reds: "KNOWN RED, do not misattribute: broker-one-connection, seat-instruction-encoding, 5 tui-durable-*".
+// A list in a body is a SNAPSHOT with no date and no cause. Two failures followed from that:
+//   1. STALENESS - impl caught pm's "seven red at 557ceb3" list (#3692) naming four demos that were already
+//      green by the time the entry was written;
+//   2. FLATTENING - "5 tui-durable-* are pre-existing" put THREE different owners in one bucket: two content
+//      clobbers, two dependency-state artifacts (ERR_PACKAGE_PATH_NOT_EXPORTED './codemode'), and one Windows
+//      EPERM environment artifact. A verifier that cannot tell a clobber from an environment artifact reads
+//      "ignore all red", which is exactly how #2279's blanket "37 pre-existing failures not introduced by
+//      this change" went false in both directions at once.
+//
+// WHAT THIS MODULE IS. A parser, a validator and a comparator for `docs/FAILURE-LEDGER.md`, whose rows carry
+// five fields: the demo, the CLASS, the OWNER item, the CONDITION under which it clears, and the DATE the
+// classification was last measured. A landing entry cites the ledger instead of copying it; a citation cannot
+// go stale the way a copy does, and where the ledger itself is stale, the date says so.
+//
+// WHAT IT DOES NOT DO. It does not decide a class. The class is a human/seat declaration backed by the
+// signature; this module checks that the declaration still MATCHES the suite, and names every red that has no
+// row (an unclassified red is the hole "ignore all red" lives in). Cause grouping is reused from
+// tools/suite-signature.mjs (#6176) rather than re-implemented here - two classifiers would drift, and drift
+// is the thing being fixed.

+import { classify } from "../tools/suite-signature.mjs";
+
+/** The vocabulary. A red whose cause fits none of these gets a NEW class, never a borrowed one. */
+export const CLASSES = [
+  "content-clobber",       // tracked content changed and broke the test (restoring the content clears it)
+  "dependency-artifact",   // the resolved dependency set / pin link state, not the code
+  "environment-artifact",  // host/OS/permission state of the machine running the suite
+  "fixture-drift",         // the test's own fixture is stale against the tree it probes
+  "accepted-defect",       // a known defect with an owner item that has not landed yet
+];
+
+const BLOCK = /```json:failure-ledger\n([\s\S]*?)```/;
+
+/** A row measured longer than this ago is AGING: still valid, but the reader should re-measure before
+ * trusting it. Aging is reported, never fatal - red sets move and nobody can keep a date current by force. */
+export const AGING_DAYS = 14;
+
+/** Parse the ledger document. Returns {rows, errors} - never throws, so a bad ledger is reportable rather
+ * than fatal: a rig whose ledger is malformed must still be able to say what is wrong with it. */
+export function parseLedger(text) {
+  const m = BLOCK.exec(String(text ?? ""));
+  if (!m) return { rows: [], errors: ["no ```json:failure-ledger block found in the ledger document"] };
+  let parsed;
+  try {
+    parsed = JSON.parse(m[1]);
+  } catch (err) {
+    return { rows: [], errors: [`the ledger block is not valid JSON: ${err.message}`] };
+  }
+  const rows = Array.isArray(parsed) ? parsed : Array.isArray(parsed?.rows) ? parsed.rows : [];
+  const errors = [];
+  for (const [i, row] of rows.entries()) {
+    const bad = validateRow(row, i);
+    if (bad.length) errors.push(`row ${i} (${row?.demo ?? "?"}): ${bad.join("; ")}`);
+  }
+  return { rows, errors };
+}
+
+/** A row is only usable if every field a reader needs is present and shaped. */
+export function validateRow(row, index = 0) {
+  const errors = [];
+  if (!row || typeof row.demo !== "string" || !row.demo.trim()) errors.push("demo is required");
+  if (!CLASSES.includes(row?.class)) errors.push(`class must be one of ${CLASSES.join(", ")} (got ${String(row?.class)})`);
+  const owner = row?.owner;
+  if (typeof owner !== "string" || !owner.trim()) errors.push("owner is required (an item id like #6646, or a named seat/operator)");
+  if (typeof row?.clearsWhen !== "string" || !row.clearsWhen.trim()) errors.push("clearsWhen is required (the condition that makes this red green)");
+  if (!/^\d{4}-\d{2}-\d{2}$/.test(String(row?.measuredOn ?? ""))) errors.push("measuredOn must be an ISO date YYYY-MM-DD");
+  if (row?.evidence !== undefined && typeof row.evidence !== "string") errors.push("evidence must be a string (a command, a sha, a row id)");
+  return errors;
+}

+/**
+ * Compare the ledger against a suite capture (the runner's stderr, in the format
+ * tools/suite-signature.mjs parses). Returns:
+ *   groups       - every cause group the capture produced, with its members
+ *   unclassified - reds with no ledger row (the dangerous set: "ignore all red" starts here)
+ *   cleared      - ledger rows whose demo is not red in this capture (the ledger is stale)
+ *   drift        - ledger rows still red, but whose recorded signature no longer matches what is failing
+ *   rows         - the ledger rows, annotated with their current state
+ */
+export function compareLedger(ledgerText, capture) {
+  const { rows, errors } = parseLedger(ledgerText);
+  const classified = classify(capture);
+  const groups = classified.groups ?? [];
+  const byFile = new Map();
+  for (const g of groups) for (const member of g.members) byFile.set(member, g);
+
+  const annotated = rows.map((row) => {
+    const group = byFile.get(row.demo);
+    // The signature is compared as a PREFIX: the label embeds an absolute worktree path, so a stored
+    // signature naming the error class and the site survives a different checkout while still catching a
+    // genuine change of cause.
+    const matches = group && (!row.signature || group.label.startsWith(row.signature));
+    const age = ageInDays(row.measuredOn);
+    return {
+      ...row,
+      state: !group ? "cleared" : matches ? "red" : "drift",
+      ageDays: age,
+      aging: age !== null && age > AGING_DAYS,
+      currentSignature: group?.label ?? null,
+    };
+  });
+
+  const covered = new Set(rows.map((r) => r.demo));
+  const unclassified = [...byFile.keys()].filter((f) => !covered.has(f));
+
+  return {
+    groups,
+    rows: annotated,
+    unclassified,
+    cleared: annotated.filter((r) => r.state === "cleared").map((r) => r.demo),
+    drift: annotated.filter((r) => r.state === "drift").map((r) => r.demo),
+    aging: annotated.filter((r) => r.aging).map((r) => `${r.demo} (${r.ageDays} days)`),
+    ledgerErrors: errors,
+    redCount: byFile.size,
+    causeCount: groups.length,
+    blocksClassified: classified.blocks,
+  };
+}

+/** The line a landing entry or verify report should PASTE INSTEAD OF A LIST: a pointer plus the count, so
+ * the reader goes to the dated source rather than trusting the copy. */
+export function citationLine(status, path = "docs/FAILURE-LEDGER.md") {
+  const classes = status.rows
+    .filter((r) => r.state !== "cleared")
+    .reduce((acc, r) => {
+      acc[r.class] = (acc[r.class] ?? 0) + 1;
+      return acc;
+    }, {});
+  const classText = Object.keys(classes).length
+    ? Object.entries(classes).map(([c, n]) => `${n} ${c}`).join(", ")
+    : "none classified";
+  const lastMeasured = status.rows
+    .filter((r) => r.state !== "cleared")
+    .map((r) => r.measuredOn)
+    .sort()
+    .pop() ?? null;
+  const stale = status.cleared.length ? ` - STALE: ${status.cleared.length} row(s) name a demo that now passes` : "";
+  const unclassifiedNote = status.unclassified.length
+    ? ` - UNCLASSIFIED RED (no row): ${status.unclassified.join(", ")}`
+    : "";
+  return (
+    `failure ledger ${path}: ${status.redCount} red in ${status.causeCount} cause(s), classified ${classText}` +
+    (lastMeasured ? `, last measured ${lastMeasured}` : "") + stale + unclassifiedNote
+  );
+}

+/** Render the ledger as one line per red, grouped by class - the human view of the machine block. */
+/** How old a classification is, in days; null when the date is not a real date. */
+export function ageInDays(measuredOn, now = new Date()) {
+  const parsed = Date.parse(String(measuredOn ?? ""));
+  if (Number.isNaN(parsed)) return null;
+  return Math.floor((now.getTime() - parsed) / 86400000);
+}

+/** Render the ledger as one line per red, grouped by class - the human view of the machine block. */
+export function renderLedger(status, path = "docs/FAILURE-LEDGER.md") {
+  const lines = [citationLine(status)];
+  for (const row of status.rows) {
+    lines.push(

+        `measured ${row.measuredOn}  clears when: ${row.clearsWhen}` +
+        (row.state === "cleared" ? "  [NOT RED IN THIS RUN - stale row]" : row.aging ? `  [aging: ${row.ageDays} days]` : ""),
+    );
+  }
+  for (const file of status.unclassified) lines.push(`  ${file.padEnd(34)} UNCLASSIFIED - no row in the ledger`);
+  return lines.join("\n");
+}

+/** The tree the reading code runs in + the store it read. Pure enough to assert in a demo. */
+export function censusProvenance(dbPath, plane = null) {
+  const repoRoot = dirname(dirname(fileURLToPath(import.meta.url)));
+  const git = gitProvenance(repoRoot);
+  return {
+    plane: plane ?? "direct store read",
+    db: dbPath,
+    tree: git.revision,
+    dirty: git.dirty,
+    treeReason: git.reason,
+    measuredAt: new Date().toISOString(),
+  };

+/** One line: which plane, which store, which tree. Never a bare number. */
+export function formatCensusProvenance(p) {
+  if (!p) return "continuity notes: provenance unknown (the census did not record its plane)";
+  const tree = p.tree
+    ? p.tree + (p.dirty === true ? " DIRTY" : p.dirty === false ? " clean" : " tree unreadable")
+    : `tree unknown (${p.treeReason ?? "unavailable"})`;
+  return `plane: ${p.plane} · store ${p.db} · code ${tree} · measured ${p.measuredAt}`;
