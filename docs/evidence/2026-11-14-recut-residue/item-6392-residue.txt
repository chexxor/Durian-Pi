+// src/inboxcensus.mjs — count the STRANDED INBOX population from the spool FILES (#5275 / ROADMAP 329).
+//
+// ONE OWNER: `check`'s `inbox-stranded` rule (#6392) and `tools/stranded-inbox.mjs` both call
+// `readInboxCensus` here. Two implementations of one classification is the drift the
+// `doc-count-drift` rule exists to catch, so the tool became a printer over this function rather
+// than a second census.
+//
+// WHY FILES AND NOT THE STORE (the contract #6392 set): a diagnostic that opens the store can be
+// starved by exactly the condition it is meant to diagnose — the wedge this census looks for is a
+// broker that is not completing passes, and a store-open census is the first thing such a broker
+// makes time out. `sharedTreeBranch` and `citations` read off-store input for the same reason. A
+// census that depends on the thing being wedged is not a census.
+//
+// WHY BOUNDED: the census reads files, so the only way it hangs is a huge spool or a huge log.
+// Both are capped: the log is read from its tail (only the last lines can matter to "when did the
+// last EXIT/PASS/START happen"), and the spool is read up to `maxEntries`. A census that truncates
+// says so in `truncated`, because a count that quietly omits entries is a false green (#6372).
+//
+// WHAT THE CLASSES MEAN — they need different clocks, which is why one number is not enough:
+//   shutdown-stranded  written AFTER the last EXIT line of the run that received it, with no START
+//                      since: it outlived the broker that took it, and no future drain will see it.
+//   drain-stranded     written AFTER the last completed PASS, and the drain clock is older than
+//                      DRAIN_STRAND_MS: the drain runs only at the start of a pass (src/broker.mjs
+//                      "only a PASS drains it"), so a broker that has not completed one for minutes
+//                      is not draining, and intents pile up behind it. A live heartbeat does NOT
+//                      clear this — liveness and progress are different facts (F7).
+//   pending            written after the baseline but the clock has not yet crossed the bound: a
+//                      normal in-flight intent, not a finding. Reporting this count is what stops
+//                      the rule from crying on a healthy broker.
+//
+// A brand-new broker has no PASS line and `lastPassAt: null` (#5698): there is no drain clock yet,
+// so nothing can be stranded. That is judged from START — a broker that started seconds ago is
+// pending; one that started an hour ago and has never completed a pass while intents wait is a
+// finding, and the detail says "no PASS has ever completed" rather than inventing a stale baseline.

+/** How stale the drain clock must be before un-swept intents count as stranded. Two minutes: the
+ * wake loop treats a non-empty inbox as wake-relevant (src/broker.mjs:1895-1899), so a healthy
+ * broker drains within a pass or two — seconds. The observed wedge was 22731 s. */

+/** Cap on spool files read, so a wedged drain cannot make the census unbounded. */
+export const MAX_SPOOL_ENTRIES = 2000;
+/** Cap on the bytes of the broker log read: only the tail can answer "when was the last PASS". */
+export const LOG_TAIL_BYTES = 262_144;

+export function spoolPaths(dbPath) {
+  return {
+    inbox: `${dbPath}.broker.inbox`,
+    error: `${dbPath}.broker.inbox.error`,
+    out: `${dbPath}.broker.inbox.out`,
+    log: `${dbPath}.broker.log`,
+    state: `${dbPath}.broker.json`,
+  };

+/** Read the last `cap` bytes of a file; a missing/unreadable file reads as "". */
+function readTail(path, cap) {
+  let text = "";
+  try {
+    text = readFileSync(path, "utf8");
+  } catch {
+    return "";
+  }
+  return text.length > cap ? text.slice(-cap) : text;

+// Broker log lines are `<ISO ts> <WORD> ...` (logBrokerLine, src/broker.mjs:2312).

+  if (!line) return null;
+  const space = line.indexOf(" ");
+  if (space <= 0) return null;
+  const at = Date.parse(line.slice(0, space));
+  return Number.isNaN(at) ? null : at;

+  for (let i = lines.length - 1; i >= 0; i -= 1) {
+    if (pattern.test(lines[i])) return lines[i];

+  return null;
